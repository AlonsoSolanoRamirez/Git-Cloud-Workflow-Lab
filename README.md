# Git Cloud Workflow Lab

This project demonstrates a practical Git workflow used in cloud and infrastructure environments.

The goal of this lab is to practice version control concepts that are commonly used by engineers working with cloud infrastructure, automation and CI/CD pipelines.

---

## Objectives

This project demonstrates the following Git skills:

- Creating and managing commits
- Tracking changes using Git history
- Reverting incorrect changes safely
- Working with remote repositories (GitHub)
- Creating version tags for releases

---

## Project Structure

Repository files:

cloud-infrastructure.txt
README.md

The file **cloud-infrastructure.txt** contains simple infrastructure documentation used for this Git workflow practice.

---

## Git Concepts Practiced

During this lab the following Git operations were performed:

- git init
- git add
- git commit
- git status
- git log
- git revert
- git push
- git pull
- git tag

These operations represent a basic Git workflow used in modern cloud engineering environments.

---

## Release Versions

Two project versions were created using Git tags:

v1.0 - Initial infrastructure documentation
v1.1 - Updated documentation with future improvements

Git tags are commonly used to mark stable releases that can be used in automated deployments.
